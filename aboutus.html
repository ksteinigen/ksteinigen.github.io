The person behind the project

About this project.

Goodkind is a course project that imagines a neighborhood pet-care service and explores how a simple website can help pet parents learn about services, manage visits, and understand sample data.

👋

Student developer

A learner building for the web.

I’m a student learning how web technologies work together. Building Goodkind gave me practice organizing a multi-page site, creating a consistent interface, and adding useful interactions with JavaScript.

View my GitHub repository ↗
🧩

How it was built

Three web technologies, working together.

  • HTMLStructures the pages, forms, and navigation.
  • CSSCreates the shared colors, layout, and responsive design.
  • JavaScriptPowers the sample care-record CRUD and chart.
  • Chart.jsVisualizes the sample pet-service data.

A note about the demo

Practice project, not a live pet-care business.

The records and analytics are sample data for demonstrating an interface. Changes to care records are saved in this browser only; there is no server or real appointment system connected.
